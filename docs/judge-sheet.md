# Whiteboard Alive: Draw your own diagram

Draw a physics diagram, we take a photo, and **your lines start to move**.

## 1. Pick one of these five

| Diagram | Draw this | It will... |
|---|---|---|
| **Pendulum** | A ceiling line, a string hanging from it, a circle at the end | swing |
| **Spring** | A ceiling (or wall) line, a zig-zag, a box at the end | bounce |
| **Incline** | A triangle, with a box sitting on the slope | slide down |
| **Projectile** | A ground line, a ball, and an arrow (or a cannon) pointing where it goes | fly in an arc |
| **Pulley** | A circle near the top, a line down each side, a box on each line (make one bigger) | the heavier side drops |

Anything else? Draw it anyway. If we can't tell what it is, it still falls.

## 2. How to draw it so it works

- **Draw big**: the diagram should fill at least half of the paper.
- **Use the dark marker** and press firmly.
- **Keep lines connected**: the string touches the ceiling, the zig-zag touches the box.
- **Keep words and numbers away from the parts**, about one finger's width, so they don't get mixed up with the lines.

## 3. Optional: add numbers

Write a number and a unit next to a part, and the simulation uses that value. For example:

- next to the string: **1 m**
- inside or next to a weight: **2 kg**
- next to a spring: **k = 20 N/m**
- near the bottom corner of a ramp: **30°**

Use plain digits and units, written in English.

## 4. Taking the photo

- Hold the phone **straight above** the paper.
- Make sure the **whole sheet** is in the shot.
- Avoid casting the phone's shadow over the drawing.

Then watch it move. You can also change gravity with the slider, tap **Moon**, or tap **Talk** and say *"make gravity weaker"*.
