## 締切と前提

- **締切: 2026-10-11（日）15:30 PDT**（Devpost の表記は "Oct 11, 2026 @ 3:30pm PDT"）。遅れた提出は受け付けない
- 制作期間: 10/10 9:15 〜 10/11 15:30。この間に作ったものだけが有効
- 対面のイベント。会場（OCC Ballroom、College Center 3階）での**チェックインが無いと提出は無効**。**審査中は会場にいる必要がある**
- **大会サイト occhacks.com での事前登録が必須**（Devpost の Join とは別）
- 部門は1つだけ選ぶ: Entertainment / **Education** / Productivity and Utility（Whiteboard Alive は Education）
- チームは最大4人。提出と、メンバーの招待をするのは1人だけ
- AI の利用は許可されている
- 審査基準: Technical Complexity、Creativity、Functionality、Presentation

## 提出に必要なもの（Devpost に書かれている必須項目）

| 項目 | 内容 | 用意できているか |
|---|---|---|
| GitHub リポジトリのリンク | 入れる場所は2つある。必須の欄（提出の詳細）と、任意の "Try it out links"（公開ページに出る）。両方に入れる | 用意済み: https://github.com/LukeNicholls1222/whiteboard-alive |
| 動いている証拠 | 画像ギャラリーにスクリーンショット。動画は**任意**で、出すなら短く | 未作成 |
| プロジェクトの要約 | "About the project" 欄に**1段落で**書く。最初の3つの見出し（Inspiration / What it does / How we built it）を目安にする。字数の上限・下限は無いが、短く | 下書きは docs/devpost.md。長いので1段落に縮める必要がある |
| チームメンバー全員 | 提出者が Devpost でメンバーを招待する | 1人ならこのままでよい |
| Tagline | 一言の売り文句。要約とは別物（要約を書く欄ではない） | docs/devpost.md の Tagline を使う |
| Built With | 必須とは書かれていないが、Devpost の標準の欄 | docs/devpost.md の Built With を使う |
